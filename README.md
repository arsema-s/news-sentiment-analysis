# News Sentiment Analysis for Stock Price Prediction

## Project Overview

This project analyzes financial news headlines and historical stock price data to investigate the relationship between news sentiment and stock market movements.

## Business Objective

Nova Financial Solutions aims to improve financial forecasting accuracy by leveraging sentiment extracted from financial news headlines and correlating it with stock price movements.

## Project Tasks

### Task 1 — Exploratory Data Analysis
- Descriptive statistics
- Publisher analysis
- Topic modeling
- Time series analysis of publication frequency

### Task 2 — Quantitative Financial Analysis
- Stock price preprocessing
- Technical indicators:
  - SMA
  - EMA
  - RSI
  - MACD
- Financial metrics using PyNance

### Task 3 — Correlation Analysis
- Sentiment analysis using VADER
- Daily stock return calculation
- Pearson correlation analysis
- Visualization and interpretation
